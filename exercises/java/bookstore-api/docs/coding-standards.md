# Team's Coding Standards

## Core Engineering Guidelines

* **Framework & Idiomatic Conventions:** Standard Java and modern Spring Boot practices.
* **Dependency Injection:** Favor constructor injection over field injection.
* **Data Immutability:** Favor immutability where applicable (e.g. records for DTOs).
* **Testing Standards:** Favor JUnit 5 / JUnit Platform and AssertJ fluent assertions (`assertThat(...)`).
* **Documentation:** Clear Javadoc and OpenAPI annotations.
